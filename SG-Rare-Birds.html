eBird API Key Required

This app requires an eBird API key to fetch rare bird alerts. Don't worry - it's free and takes less than a minute!

How to get your free API key:

  1. Visit ebird.org/api/keygen
  2. Fill out the simple form (name, email, intended use)
  3. Check your email for the API key
  4. Copy and paste it below

Your API key is stored locally in your browser and never sent anywhere except eBird's servers.

You can update your API key anytime by clicking the button in the header.
